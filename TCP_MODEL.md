TCP = Transmission Control Protocol

There are five layers

**5. Application Layer**

- protocolos: HTTP/SMTP/IMAP/POP3/FTP/SSH

(Indirectly Merged in Application Layer)
**Presenation Layer**

- Encoding/Encryption/Serialization/JSON

(Indirectly Merged in Application Layer)
**Session Layer**

- RPC/NETBIOS/Session Management

**4. Transport Layer**

- TCP/UDP/QUIC
- Ports
- Data Units (TCP - Segment, UDP - Datagram)

**3. Network Layer**

- IP/ICMP

**2. Data Link Layer**

- MAC/Ethernet

**1. Physical Layer**

- Electrical Signals / Radio Waves
- Binary
